# Prato Rápido

Catálogo de receitas simples do dia a dia, desenvolvido no Trabalho Prático Individual da disciplina de Desenvolvimento de Interfaces Web (PUC Minas).

## Entidade principal

**Receita**: nome, categoria, tempo de preparo, porções, dificuldade, ingredientes, modo de preparo, imagem e favorita.
